# Supermarket Sales Analysis Using Microsoft Excel
# Project Overview
This project focuses on analyzing supermarket sales data using Microsoft Excel to understand revenue patterns, transaction distribution, and sales performance across different years and locations.

The project applies descriptive statistics, PivotTables, Excel formulas, and regression analysis to transform raw sales data into meaningful information that can support business decision-making.

# Business Problem
Supermarkets generate large amounts of transaction data, but raw data alone does not explain how sales are performing, how transaction values vary, or which locations contribute more revenue.

Without proper analysis, management may struggle to identify sales patterns, investigate unusual transactions, and make informed decisions.

This project demonstrates how Excel can be used to explore these questions and extract useful business insights from sales data.

# Project Objectives
Analyze revenue patterns across different years.
Calculate typical transaction revenue using measures of central tendency.
Measure variations in transaction revenue.
Identify minimum, maximum, and percentile values.
Compare revenue across countries, cities, and years.
Explore relationships in the data using regression analysis.
Demonstrate how statistical analysis supports business decisions.

# Analysis Performed
1. Measures of Central Tendency
Mean, Median, and Mode

# These calculations help summarize transaction revenue and understand typical purchasing patterns.

Mean: Calculates the average revenue per transaction.
Median: Identifies the middle transaction revenue value and provides a measure less affected by extreme values.
Mode: Identifies the most frequently occurring revenue value.
Business value: These metrics help management understand typical transaction values and compare sales patterns across different periods.

2. Measures of Variability
Variance and Standard Deviation

These metrics measure how widely transaction revenue values are distributed around the average.

Variance: Measures the dispersion of revenue values using squared deviations from the mean.
Standard deviation: Measures the spread of revenue values in the same units as revenue.
Business value: These calculations help assess transaction variability and identify periods or transactions that may require further investigation.

3. Minimum and Maximum Revenue
The MIN and MAX functions identify the lowest and highest revenue values within a selected dataset.

Business value: These calculations help identify extreme transactions and provide a starting point for investigating unusual purchasing behaviour or potential data-quality issues.

4. Quartile and Percentile Analysis
Quartiles and percentiles help explain how transaction revenue is distributed across the dataset.

The analysis includes:

First quartile (Q1)
Second quartile (Q2 or median)
Third quartile (Q3)
1st and 5th percentiles
75th and 95th percentiles
99th percentile
Business value: These measures help distinguish lower-value transactions from higher-value transactions, understand spending distributions, and investigate unusually low or high revenue values.

5. Revenue Comparison Using PivotTables
PivotTables are used to summarize and compare revenue across countries, cities, and years.

Business value: This approach makes it easier to compare sales performance across locations, identify differences in revenue contribution, and investigate changes over time.

6. Regression Analysis
Regression analysis is used to explore relationships between variables and assess how well a statistical model explains variation in an outcome.

Business value: It provides a framework for investigating potential relationships in sales data. Model significance and explanatory power must be evaluated before drawing conclusions or using the model for forecasting.
